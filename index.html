⚡ Syarat Deployment

✓ File utama harus bernama index.html.
✓ Ukuran file maksimal 1 MB.
✓ Website yang di-deploy akan bersifat publik.
✓ Dilarang menggunakan konten ilegal atau phishing.
✓ Gunakan nama website yang valid dan mudah diingat.

📖 Cara Deploy Website

1. Buat website kamu
Siapkan website HTML yang ingin kamu deploy.
2. Pastikan file bernama index.html
Halaman utama website harus menggunakan nama index.html.
3. Masukkan nama website
Gunakan huruf kecil, angka, dan tanda -.
4. Upload index.html
Klik area upload atau tarik file ke dalam kotak upload.
5. Klik Deploy Website
Tunggu beberapa saat sampai proses deployment selesai.
6. Buka website
Setelah berhasil, klik URL yang muncul pada hasil deployment.
7. Bagikan URL
Website kamu sekarang sudah bisa dibuka dan dibagikan kepada orang lain.

🌐 Setelah Berhasil Deploy

‼️ Jangan langsung buka website setelah selesai deploy, ganti dulu domainnya. contoh: https://Lumnztyz-iajshj-sixcore1.vercel.app, hilangkan (lajshj-sixcore1), jadi domainnya nanti jadi cuma https://Lumnztyz.vercel.app.
✓ Buka URL hasil edit deployment tadi.
✓ Periksa apakah seluruh tampilan website sudah sesuai.
✓ Jika website sudah benar, simpan URL tersebut.
✓ Bagikan URL website ke teman atau media sosial.
✓ Jika ingin memperbarui website, deploy ulang menggunakan nama website yang tersedia.
